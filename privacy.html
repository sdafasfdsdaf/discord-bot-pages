Политика конфиденциальности

Последнее обновление: 18 сентября 2026 г.

Эта Политика конфиденциальности описывает, какие данные может обрабатывать Discord-приложение «Discord Bot» (далее — «Приложение») и для чего они используются.

1. Какие данные могут обрабатываться

В зависимости от функций Приложения могут обрабатываться данные, предоставляемые Discord API, например идентификаторы пользователей, идентификаторы серверов, идентификаторы каналов, роли и данные взаимодействия с командами.

2. Для чего используются данные

Данные используются только для работы функций Приложения, обработки команд, выполнения настроек сервера и обеспечения работы его функций.

3. Хранение

Если Приложение сохраняет данные, они хранятся только в объёме, необходимом для работы соответствующей функции. Данные, которые больше не нужны для работы Приложения, должны удаляться в разумный срок.

4. Передача данных

Мы не продаём персональные данные. Данные могут обрабатываться инфраструктурой и сервисами, необходимыми для работы Приложения, а также передаваться через Discord API в рамках работы Discord.

5. Безопасность

Мы принимаем разумные меры для защиты данных от несанкционированного доступа, изменения или раскрытия.

6. Изменения политики

Эта Политика может обновляться. Актуальная версия всегда публикуется на этой странице.

7. Контакты

По вопросам конфиденциальности используйте контакт, указанный на странице приложения в Discord.
